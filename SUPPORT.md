# Support

Use GitHub issues for reproducible NSDeck defects and feature requests. This community repository does not provide an SLA, emergency DNS recovery, or support for third-party provider outages.

Before opening an issue:

1. Upgrade to the latest release.
2. Confirm the problem with the provider's own console when safe to do so.
3. Export NSDeck's **Shareable Diagnostic Report**.
4. Replace any remaining organization-specific details with reserved examples.

Never post provider credentials, service-account files, settings, raw logs, snapshots, JEA transcripts, internal server names, or production DNS records. Report security vulnerabilities using the process in [SECURITY.md](SECURITY.md).
